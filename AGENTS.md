# AGENTS.md

Instructions for AI agents (and humans) working in this repository.

## What this is

A Polish-language handbook for **Warhammer 40,000: Kill Team, 3rd edition (2024)**, written so an
**11-year-old** can follow it. This folder is the **permanent source of truth**. Content is published
from here to a **self-hosted Wiki.js** instance — never edit the wiki first and let this repo drift.

Rules state covered: Core Book 2024, Approved Ops 2025, and all official updates up to the
**October 2026** update (published 28 Oct 2026). Last content pass: **23 Nov 2026**.

## Writing conventions (must follow)

- **Language:** Polish, plain, short sentences, addressed to the reader as "ty". Target reader: 11 years old.
  Not patronizing — explain, don't baby-talk.
- **Game terms stay in English**, with a Polish translation in brackets, then the rule after a colon:
  `**Silent** (Cicha): możesz strzelać z tej broni, nawet gdy twój żołnierz się ukrywa.`
  Weapon names in tables: `Slugga (Pistolet)`.
- **Callouts:** `> 💡 **Wskazówka:**` for tips, `> ⚠️ **Uwaga:**` for common mistakes. No other emoji.
- **Weapons table columns:** `Broń | Atk | Hit | Dmg | Cechy`. Stats table: `APL | Move | Save | Rany | Podstawka`.
- **Units:** inches written as `6"`. VP/CP/AP/APL abbreviations as in `podrecznik/README.md`.
- **Navigation:** every page starts and ends with a nav line (`[← …](…) · [Spis podręcznika](…) · …`).
- **Each page ends with a `**Źródła:**` list** of URLs used.
- New glossary terms → add to `06_slowniczek.md` (alphabetical, with part number).

### Team pages (`podrecznik/07_oddzialy/<team>.md`)

Use the same 10 sections as `kommandos.md` (template): W skrócie · Skład oddziału · Zasady oddziału ·
Strategy Ploys · Firefight Ploys · Sprzęt oddziału · Żołnierze (one H3 per operative, stats table + weapons
table + abilities) · Jak grać · Jak grać przeciwko · Najczęstsze pytania. State the rules version/date at the
top. Add the team to `07_oddzialy/README.md` (table) and remove it from "W przygotowaniu".
File names: lowercase-kebab of the official team name (e.g. `corsair-voidscarred.md` — note the three
existing files use single-word names).

## Accuracy rules (must follow)

1. **Never invent numbers.** If a value can't be confirmed from a source, leave a blank / say "sprawdź na
   karcie".
2. **Write research notes first** into `research/` (English, terse), then write the Polish page from them.
   Cross-check every weapon/stat row in the page against the notes before finishing.
3. **Source priority:** official GW PDFs / Kill Team app > Wahapedia (`wahapedia.ru/kill-team3/…`) >
   reviews (Goonhammer etc.). Reviews are only for tactics advice, never for rule text.
4. **Always check for newer updates** (warhammer-community.com/en-gb/downloads/kill-team/ and WHC
   "Kill Team … update" articles) before writing or revising a team page.
5. **Tactics sections are synthesis**, not official — keep them clearly advisory.

### Known unverified items

- Ploy CP costs: handbook states "1 CP" everywhere (3rd-ed standard) — not verified per ploy.
- Approved Ops 2025 Crit/Tac Op descriptions are reconstructed (full card text is paywalled); some
  details deferred to "sprawdź na karcie" (Plant Banner distance, Track Enemy TP4 scoring, Rout TP limits).

## Images

- `podrecznik/obrazki/01–12_*.png` are generated by `scripts/diagrams_core.py` (01–08) and
  `scripts/diagrams_missions.py` (09–12): `python3 scripts/diagrams_core.py podrecznik/obrazki`.
  They may be replaced by nicer versions under the **same filenames** (see `prompty_obrazki.md`).
- `podrecznik/obrazki/ilustracje/il_*.png` are generated by `scripts/gen_illustrations.py`, which feeds
  Part A of `prompty_obrazki.md` (STYL A + negatives) to `codex exec` (image_generation feature). It only
  creates missing files — delete one to regenerate it. Review every result for GW look-alikes (emblems,
  e.g. eagles/skulls on armour), text and gore before committing.
- **No Games Workshop IP in generated images**: no "Warhammer", "Space Marine", faction names, logos, or
  recognisable GW miniatures in prompts or outputs; no text in images (models garble Polish diacritics);
  no gore (child audience). That's why team pages have no illustrations.

## Publishing to Wiki.js

Wiki: **https://kt.litwiniuk.net** (Wiki.js 3.6, private — readers must log in). Publish with:

```
mise exec -- python3 scripts/publish_wiki.py              # images + pages
mise exec -- python3 scripts/publish_wiki.py --dry-run    # convert only → build/wiki/
mise exec -- python3 scripts/publish_wiki.py --skip-assets --only misje,sprzet
```

`WIKIJS_TOKEN` comes from `.mise.toml` (git-ignored). It must be a **personal access token** (profile →
Tokens) with Pages + AI Assistants (MCP) read & write and Assets write — API keys can't save pages or
upload assets. The script is idempotent (unchanged pages are skipped). What it does / why:

- Pages live at the wiki root: `README.md` → `/home`, `02_misje.md` → `/misje`,
  `07_oddzialy/kommandos.md` → `/oddzialy/kommandos` (map in `PAGES`). **New team page → add it to `PAGES`.**
- H1 → page title, bold subtitle line → description; `.md` links → wiki paths; GitHub anchors →
  Wiki.js anchors (Wiki.js collapses `--`, keeps Polish letters); `prompty_obrazki.md` is not published
  (links to it become text); the README "Obrazki" section is dropped.
- Images are uploaded over REST to `/_files/obrazki/…`; Wiki.js sanitizes names (`01_control_range.png`
  → `01-control-range.png`); illustrations go up as 1600px JPEGs.
- Pages are saved through the wiki's **MCP endpoint** (`/_mcp`), not REST: a REST save without
  browser-made `render` HTML stays blank, MCP saves are rendered server-side.
- REST quirks: `GET /_api/sites` is admin-only (use `/_api/sites/<hostname>`); the page list endpoint is
  unimplemented (pages are looked up by the cyrb53 hash of their path); Cloudflare blocks Python's default
  User-Agent. API reference: `https://kt.litwiniuk.net/_api` (Swagger), spec at `/_api/json`.
- The theme lives in `wiki/` (see `wiki/README.md`); PATs can't set it, so it's applied in Admin → Theme.
- **Official GW photos are wiki-only** (private wiki; this repo is public, so they never go into
  `podrecznik/` or git). `wiki/official/manifest.json` + `wiki/official/parts/*.json` list image URLs per
  page heading (team photo under "1. … w skrócie", one cut-out per operative H3, killzone photos); the
  publisher downloads them (cache in `wiki/official/cache/`) and inserts them under those headings.
  Sources: warhammer40000.com/games/faction/… pages (operative cut-outs) and Warhammer Community articles.
  New team page → add its entries; a renamed heading breaks its image (the publisher warns).
- The sidebar (site-wide menu) is maintained by hand in the wiki; the Oddziały submenu lists team pages.
- Keep the source files free of wiki-specific syntax; do the conversion in the publish script.

# Approved Ops 2025 — notatki z Goonhammer review + WHC + Tournament Companion
Maps: Volkus redrawn, Bheta-Decima partly changed, Tomb World added, Gallowdark unchanged; + general boards. Companion adds 6 Octarius maps.
Initiative pre-TP1: roll-off, winner decides who has initiative; initiative player picks drop zone; other player gets card to re-roll initiative later.
Each TP: roll; ties -> player without initiative decides? ("Ties go to player without initiative"); loser of roll may play cards/team abilities first alternating; team abilities before cards. Winner decides who has initiative. Loser gains Modify Initiative card value = current TP number. Cards held, add/subtract.
Scouting Phase removed.
Crit Ops groups: A: 1 Secure, 2 Loot, 3 Transmission; B: 4 Orb, 6 Energy Cells, 7 Download; C: 5 Stake Claim, 8 Data, 9 Reboot.
Orb: starts centre obj. Move Orb 1AP: if orb on your obj -> centre; if centre -> opp obj. From end TP2 each objective w/o orb worth 1VP (to controller).
Stake Claim: from TP2 Strategic Gambit choose obj + condition (friendly control at end TP / enemy not contest at end TP). True -> 1VP. each obj once per battle. Control majority -> 2nd VP.
Energy Cells: from TP2, Pick Up Marker +2AP TP2, +1AP TP3, normal TP4, can't modify. End TP: 1VP control more objs than opp; 1VP if your ops carry any obj marker. Carrier can't move >6" per TP.
Download: Download 1AP on centre or opp objective, only TP3/TP4, not already downloaded. From end TP2 1VP control majority (excluding downloaded). Download TP3=1VP, TP4=2VP. Stay downloaded.
Data: Compile Data 1AP once per TP per obj by either player. From end TP2 player with most Compile Data actions 1VP. TP4 Send Data 1AP: VP = Data on that obj. Cap 6VP.
Reboot: TP1 both secretly choose obj 1-3 (gambit). different -> the unchosen one inert; same -> that one inert. From end TP2 1VP per controlled non-inert marker. Reboot 2AP removes inert (once).
Secure/Loot/Transmission unchanged from core book.

Martyrs (op incapacitated while contesting marker -> Martyr token; from end TP2 remove any for 1VP each +1VP if you control that marker; max 2/TP).
Seek&Destroy: Rout (1VP incap enemy within 6" of opp drop zone, 2VP if 12+W). Sweep and Clear (reveal when enemy incap contesting obj or Clear 1AP; Sweep marker; from end TP2 1VP per controlled marker with Sweep +1VP if Clear done). Dominate (Dominate tokens for incapacitating; end TP3/TP4 remove tokens 1VP each max 3/TP).
Infiltration: Track Enemy (enemy tracked if friendly Conceal op within 6" not in its CR and not valid target for that enemy; from end TP2 1VP per tracked; TP4 single tracked = 2VP?). Plant Devices (1AP on controlled objectives; end TP 1VP device on enemy's objective +1VP per other device obj contested by enemy max 2/TP). Steal Intelligence (enemy incap -> Intelligence marker in its CR; carry up to 2; end TP 1VP if any carried; end last TP 1VP per carried).
Tournament: same crit op all players per round; rankings record > SoS > total VP. App online rules updates take precedence.

# Wahapedia Approved Ops 2025 — game sequence (paraphrase)
3 ops: Crit, Kill, Tac. max 6VP each op.
1 Set up battle: select kill team; killzone+terrain (specify terrain types); one shared Crit Op + objective markers (all on killzone floor except Bheta-Decima); roll-off winner decides initiative; initiative player selects drop zone; opp takes other & gains Re-roll initiative card.
2 Select operatives: secretly select ops per team selection reqs, reveal simultaneously; secretly up to 4 equipment options, no option more than once, reveal; each starts 2CP; secretly select one Tac Op from one of team's archetypes (Infiltration/Recon/Security/Seek&Destroy, per team rules).
3 Set up operatives: initiative player first, alternate setting up pre-battle equipment (eg ladders) one item at a time; then alternate setting up 1/3 of kill team (round up), wholly within drop zone, Conceal order.
4 Play: initiative each TP incl first: roll-off without re-rolling ties; starting with loser alternate playing initiative card or passing until both pass in succession. Team rules affecting roll-off resolved before cards, starting with player losing. Re-roll card; others modify up/down, results can go >6 or <1 (5 with +2/-2 -> 3 or 7). Re-roll after modify replaces mods. Winner decides initiative. Except TP4, roll-off loser gains initiative card = TP number (TP2 -> +2/-2). Ties: player without initiative wins tie.
Primary Op: Strategic Gambit TP1, secretly select one of 3 ops as primary.
5 End: 4 TPs. If one player has no ops, other plays out remaining TPs. Reveal primary ops; +VP equal half of VP scored from that op rounded up. Most VP wins; equal = draw.
Kill Op: kill grade starts 0, rises as enemies incapacitated, max 5. Each new grade 1VP. End of battle higher kill grade than opponent +1VP. Table depends on starting number of enemy ops (image).
